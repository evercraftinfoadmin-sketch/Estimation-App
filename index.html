Import Leads & Estimates

Choose a spreadsheet exported from your previous system: Excel (.xlsx) or CSV. The first row must contain the column names.

  • One row per client / estimate, or one row per service line. Rows with the same Estimate # become one estimate.
  • Useful columns: Client Name, Email, Phone, Address, Estimate #, Date, Category, Service, Quantity, Price, Total, Status, Stage, Notes. Only one of Client Name / Address / Phone / Email is required.
  • Imported estimates keep their totals (0% markup and tax). Existing estimate numbers and existing CRM clients are not duplicated.
  • A backup file (.json) from this app can be restored here too.

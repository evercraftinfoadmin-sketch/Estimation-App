# Construction Estimator

A standalone construction estimating web app for Painting, Drywall, and Stucco.

## Features
- Client and project information
- Painting / Drywall / Stucco material database
- Coverage, unit price and waste calculations
- Labor, markup and sales tax
- Estimate summary and customer price
- Browser print / Save as PDF
- Email estimate via mailto
- Persistent settings via localStorage

## Run
Open `index.html` in a browser.

## Deploy
This is a static site and can be deployed directly to Vercel or GitHub Pages.
